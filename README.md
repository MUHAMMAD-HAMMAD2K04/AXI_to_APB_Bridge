# Design and Verification of AXI–APB Bridge using UVM

A complete RTL design and UVM verification environment for an **AXI-to-APB Bridge**, developed in **SystemVerilog** following industry-standard verification methodology. This project demonstrates the complete verification flow from specification and test planning to reusable UVC development, functional verification, debugging, and regression.

---

## Overview

The AXI–APB Bridge translates AXI memory transactions into APB peripheral accesses, enabling communication between high-performance AXI masters and low-power APB peripherals.

The verification environment is built using the **Universal Verification Methodology (UVM)** and emphasizes **modularity, scalability, and reusability** through independently developed AXI and APB Verification Components (UVCs).

---

## Project Objectives

* Design an AXI-to-APB Bridge in RTL.
* Develop reusable AXI and APB UVCs.
* Verify protocol conversion for read and write transactions.
* Validate bridge functionality using constrained-random testing.
* Perform functional checking using a scoreboard.
* Collect functional coverage.
* Build a scalable verification environment suitable for future protocol extensions.

# AXI Verification Component (AXI UVC)

The AXI UVC generates and monitors AXI-side transactions presented to the bridge.

### Components

* AXI Transaction
* AXI Sequence
* AXI Sequencer
* AXI Driver
* AXI Monitor
* AXI Agent
* AXI Interface

### Responsibilities

* Generate constrained-random transactions
* Drive FIFO-based AXI requests
* Monitor DUT activity
* Convert pin-level activity into transactions
* Publish transactions through analysis ports
* Support active and passive agent configurations

---

# APB Verification Component (APB UVC)

The APB UVC verifies the APB interface generated by the bridge.

### Components

* APB Transaction
* APB Sequence
* APB Sequencer
* APB Driver
* APB Monitor
* APB Agent
* APB Interface

### Responsibilities

* Observe APB transfers
* Capture read/write operations
* Monitor APB timing and control signals
* Send transactions to the scoreboard
* Verify protocol correctness
