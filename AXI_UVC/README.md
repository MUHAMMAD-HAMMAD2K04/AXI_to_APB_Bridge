# AXI UVC (Universal Verification Component)

## Overview

The AXI UVC is a reusable UVM-based Verification Component developed to verify the AXI interface of an AXI-to-APB Bridge. It generates AXI read/write transactions, drives them to the DUT, monitors bus activity, and reconstructs protocol-level transactions for functional checking.

The UVC follows the standard UVM architecture and is designed to be reusable, configurable, and protocol-compliant.

---

## Features

- UVM compliant architecture
- Reusable AXI Verification Component
- Supports AXI Read transactions
- Supports AXI Write transactions
- Active and Passive agent configuration
- Configurable through `uvm_config_db`
- Transaction-level communication using TLM
- Monitor reconstructs bus activity into AXI transactions
- Easily extendable for bursts, outstanding transactions, and protocol corner cases

---

## UVC Architecture

```
             Test
              │
         AXI Sequence
              │
         AXI Sequencer
              │
         AXI Driver
              │
        AXI Interface
              │
             DUT
              │
        AXI Monitor
              │
        Analysis Port
```

## Components

### AXI Interface

Provides communication between the DUT and the verification environment using a virtual interface.

---

### AXI Transaction

Represents a complete AXI transaction including:

- Address
- Data
- Read/Write Information
- Burst Parameters (future extension)
- Response Information

---

### AXI Sequencer

Supplies sequence items generated by sequences to the driver.

---

### AXI Driver

Converts transaction-level objects into pin-level AXI activity and drives the DUT through the virtual interface.

---

### AXI Monitor

Passively observes the AXI interface and converts signal activity back into AXI transaction objects.

The monitor publishes transactions through an Analysis Port for scoreboards and coverage collection.

---

### AXI Agent

Bundles together:

- Driver
- Sequencer
- Monitor

Supports both Active and Passive modes.

---

### AXI Environment

Acts as the top-level container for the AXI verification environment and can be integrated into larger UVM environments.
